# Jour 4 — Endpoint, administration, détection et vulnérabilités

## Objectif de la journée

À la fin du Jour 4, NovaCorp doit disposer :
- d'un poste protégé par BitLocker ;
- d'un endpoint durci ;
- d'une administration distante sécurisée ;
- d'une télémétrie Windows centralisée ;
- d'un premier processus de vulnerability management.

## Règles
- Chaque étudiant réalise une action technique identifiable.
- Les rôles tournent à chaque module.
- Personne ne valide son propre travail.
- Les preuves doivent être conservées sans exposer de secrets.
- Les outils doivent être compris, pas simplement installés.

## Checkpoints
- CP12 : BitLocker fonctionnel
- CP13 : endpoint durci
- CP14 : administration distante sécurisée
- CP15 : événements Sysmon visibles dans Wazuh
- CP16 : scan Greenbone analysé et priorisé

Snapshot conseillé : `M16-SECURITY-OBSERVABILITY-OK`
