# Jour 1 — Fondations du laboratoire Windows

## Objectif

Poser un socle stable avant le déploiement des services de sécurité.

## Module

- M01 — Fondations du lab Windows

## Principes

- un mini-SI distribué entre les étudiants ;
- adressage et nommage cohérents ;
- contrôles système et réseau ;
- audit croisé ;
- validation avant snapshot.

## Checkpoint

À la fin du Jour 1 :
- toutes les machines démarrent ;
- les hostnames et adresses IP sont cohérents ;
- la connectivité est comprise et vérifiée ;
- le firewall reste actif ;
- les comptes locaux sont connus ;
- l'architecture est documentée ;
- chaque machine a été auditée par un autre étudiant.

Snapshot conseillé : `M01-FOUNDATION-OK`
