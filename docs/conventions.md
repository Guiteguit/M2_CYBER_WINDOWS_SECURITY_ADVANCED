# Conventions du laboratoire

## Nommage

- Noms de machines en majuscules.
- Pas d'espace ni de caractères accentués.
- Noms explicites et cohérents.

## Documentation

Tout changement important doit pouvoir être expliqué par le groupe.

Pour chaque configuration sensible, documenter au minimum :

- objectif ;
- méthode utilisée ;
- résultat ;
- risque couvert ;
- éventuel impact opérationnel.

## Git

Ne jamais versionner :

- mots de passe ;
- clés privées ;
- recovery keys ;
- tokens ;
- secrets ;
- exports contenant des données sensibles.

## Validation

Une validation doit toujours inclure une preuve :

- commande ;
- capture ;
- test ;
- événement de log ;
- résultat d'audit.
