# Livrables

Le dépôt étudiant ne doit pas devenir un rapport de 100 pages.

L'objectif est de produire des livrables **courts, professionnels et vérifiables**.

## Format recommandé

Chaque module pourra contenir :

```text
moduleXX/
├── README.md
├── architecture.md
├── validation.md
├── security-review.md
└── scripts/
```

Tous les fichiers ne seront pas obligatoires à chaque module.

## Contributions individuelles

Chaque étudiant doit laisser une trace de sa contribution dans le livrable du groupe.

Exemples :

```text
Alice — configuration de SRV01 et validation des ACL.
Bob — audit de DC01 et diagnostic DNS.
Charlie — script PowerShell d'inventaire.
David — validation réseau et documentation.
```

## Preuves

Une preuve doit permettre au formateur de vérifier rapidement un résultat.

Préférer :

- sorties PowerShell courtes ;
- tableaux ;
- commandes de validation ;
- captures utiles ;
- résultats d'outil.

Éviter les captures d'écran décoratives ou les copier/coller de documentation externe.
