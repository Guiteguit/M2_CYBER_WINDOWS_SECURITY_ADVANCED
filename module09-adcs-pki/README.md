# Module 09 — AD CS / PKI Windows

## Contexte
NovaCorp utilise encore des certificats autosignés.

## Mission
Déployez une PKI interne simple basée sur AD CS et délivrez un certificat serveur valide.

## Répartition suggérée
- A : architecture PKI
- B : installation AD CS
- C : templates / enrollment
- D : validation de la chaîne
- E : audit sécurité

## Travail demandé
- concevoir la CA ;
- installer AD CS ;
- émettre un certificat ;
- valider Subject, SAN, EKU et chaîne de confiance ;
- identifier au moins trois mauvaises pratiques PKI.

## Livrables
- `pki-design.md`
- `certificate-review.md`
- preuves dans `evidence/`

## Checkpoint CP09
- CA opérationnelle ;
- certificat serveur émis ;
- chaîne de confiance validée.
